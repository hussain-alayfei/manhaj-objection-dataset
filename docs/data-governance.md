# حوكمة البيانات

## الفصل بين الطبقات

| الطبقة | التخزين | قابلية التعديل |
|---|---|---|
| المصدر | sources + source_chunks + source/source_evidence | ثابتة عبر واجهة المراجعة |
| التحليل | ai_analysis + حقول التشخيص الحالية | مقترحات آلية أو تحرير المراجع، مع نسخ |
| الاعتماد | human_review + reviews + record_versions | أحداث وسجلات إضافية؛ لا حذف للتاريخ |

سجل الإنشاء يحدد `added_by` و`created_at`. كل تغيير يزيد `version` ويحفظ `previous_version` ولقطة قبل/بعد وفاعل التغيير ووقته. المقترحات الآلية اللاحقة تسجل `machine_proposal` دون انتحال مراجع. المراجعة باستخدام إصدار قديم ترفض بـ409 لمنع ضياع التعديلات المتزامنة.

الحالات: draft → needs_review → approved أو rejected. التحرير أو إعادة الفتح يلغيان الاعتماد الحالي. إلغاء اعتماد قاعدة يجعل الأمثلة المرتبطة غير مؤهلة للاسترجاع والتصدير، ولو ظل السجل التاريخي يحمل موافقة سابقة. الأسر التي أُلغيت موافقة مثال فيها تستبعد كذلك.

التصدير والاسترجاع يستخدمان `Store.eligible()`، لا مجرد ملفات `data/approved`. تلك الملفات لقطات لا سلطة لها على الموافقة. `data/reviewed` يجمع آخر نسخ كل ما راجعه إنسان، بما فيه المرفوض؛ لا يجوز التدريب عليه مباشرة.

صلاحية اعتماد السجلات تمنح لمراجع داخلي بقرار المشغل ورمز منفرد. لا تثبت البرمجيات الخبرة العلمية لصاحب الرمز. لا توجد موافقات آلية ولا قواعد بيانات تدريب معتمدة مُنشأة مسبقًا.

سجل PostgreSQL يمنع تعديل/حذف صفوف التدقيق عبر مشغلات SQL. مالك قاعدة البيانات الإداري يستطيع تعديل البنية؛ فصل حساب الهجرة عن حساب الخدمة وتقييد امتيازات الخدمة متطلب تشغيل. `Store` واجهة الكود الموثوقة، وليس API لإدخال JSON عشوائي من الجمهور.

لمراجعة اتفاق الخبراء اجمع تصنيفين مستقلين قبل التوفيق بينهما، واحسب نسبة الاتفاق وCohen's kappa بواسطة `reviewer_agreement`. لا تُحسب مراجعات متسلسلة متأثرة ببعضها كاتفاق أعمى مستقل.

## وضع المسودات والنماذج الخارجية

الوضع الافتراضي للتشخيص يسترجع السجلات المعتمدة فقط. وضع المسودات (`include_drafts`) اختياري لكل طلب: يضيف سجلات `needs_review` و`draft` دون `rejected`، ويعلَّم الناتج «مسودة: مستندة إلى مواد غير معتمدة» مع حالة كل قاعدة مستشهد بها. الأمثلة غير المعتمدة تُرسل للنموذج بنصها المصدري فقط دون التحليل الآلي المخزن، ومفاتيحها `candidate_*`. التصدير والمعيار والبحث الخارجي وخط الأساس تبقى على `eligible()` المعتمد فقط. التشخيص يحفظ `requested_by` و`mode` والنموذج ومعرفات المسترجع وحالاتها.

مزود OpenAI يستقبل المقتطفات المسترجعة ونص الشبهة (Responses API مع `store=False`)، وحقول السجلات لبناء فهرس التضمين. معرفات القواعد التي يقترحها النموذج تُقبل فقط إن كانت ضمن المسترجع، ونص القاعدة يستبدل دائمًا بالنص المخزن. سجل نسخة المعاينة (`READ_ONLY=1`) لا يقبل الكتابة لأن سجلات التدقيق في الإنتاج غير قابلة للحذف.
