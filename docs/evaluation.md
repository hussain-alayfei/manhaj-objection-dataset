# التقييم والتدريب

الترتيب الملزم: بيانات مراجعة → few-shot → RAG → معيار مستقل → قياس خط أساس → بحث جدوى fine-tuning. لا تدريب تلقائي.

## المقاييس

| المقياس | التنفيذ والتفسير |
|---|---|
| Primary Pattern Accuracy | مطابقة التصنيف مع المرجع؛ غياب التنبؤ إخفاق |
| Sub-pattern Accuracy | مطابقة مجموعة الأنماط الفرعية كاملة |
| Central Claim Accuracy | تحكيم ثنائي من مراجع مسمى، وفق حفظ المعنى والنطاق |
| Objection Decomposition Accuracy | تحكيم اكتمال وتمايز الدعاوى والمقارنة |
| Source Grounding Accuracy | تحكيم دعم المصدر للاستنتاج، لا مجرد وجود اقتباس |
| Citation Accuracy | تحكيم صحة المصدر والصفحة والنسبة، بعد المطابقة الآلية |
| Unsupported Diagnosis Rate | نسبة التشخيصات غير المدعومة بين الحالات المحكّمة؛ الأقل أفضل |
| Human Review Trigger Accuracy | مطابقة إشارة النموذج قبل بوابة الإنتاج مع حاجة المرجع للمراجعة |
| Duplicate Family Detection Accuracy | مطابقة معرف العائلة حيث يوجد مرجع عائلة معتمد |

كل قيمة تعرض عدد الحالات المقاسة وإجمالي الحالات. غياب التحكيم ينتج `null` لا صفرًا. درجات الإنسان في ملف `human_scores` تأتي بالشكل `{case_id: {metric: {score: 0 or 1, reviewer_id: "expert"}}}`. لا تُعلن نتيجة بحثية من حالات معدودة أو من مراجع غير مستقل.

جميع نواتج خدمة التشخيص الداخلية تتطلب مراجعة؛ لذلك قياس إشارة النموذج قبل البوابة يحتاج تنبؤات خام من تجربة مضبوطة، وليس استخدام الراية المفروضة في الإنتاج كمقياس ذكاء. أداة baseline الحالية تقيس المنتج ذي البوابة المحافظة وتُفسر بهذا القيد.

## منع التسرب

تُجمع علاقات التطابق اللفظي والعائلة والتكرار في مكونات مترابطة، وتبقى المجموعة كاملة في تقسيم واحد. حتى اقتراحات التشابه غير المعتمدة تستخدم تحفظيًا لحجب التسرب. يظل كل معرف سبق حجزه للتقييم خارج التدريب عبر جميع البيانات اللاحقة. يحظر نقل حالة سبق تصديرها للتدريب إلى اختبار مستقل. أي تغيير في نسخة المرجع يستلزم بيان تقسيم جديدًا ومراجعة أثره.

التقسيم الآلي >=100 سجل و>=20 مجموعة؛ النسب تقريبية لأن المحافظة على المجموعة أهم من نسبة دقيقة. في مجموعة V1 الأصغر يختار الخبير حالات متنوعة يدويًا، منها الامتناع والمركب والأنماط المتشابهة دون كونها الشبهة نفسها.

`run_baseline.py` يحجب الأمثلة خارج مجموعة التدريب عن الاسترجاع. لا يُشغّل benchmark قبل الاعتماد. لا توجد حالات كتاب معتمدة في التسليم، لذا لا توجد درجات نموذج أو ملفات تدريب صالحة مدعاة.

قبل fine-tuning يوثق المسؤول عدد الحالات والعائلات وتوازن الفئات واتفاق مراجعين مستقلين وأخطاء RAG/التلقين المتبقية، ثم يقرر إن كان التحسين يبرر التدريب. thresholds المعلنة في كشف التكرار اقتراحات أولية، ويجب معايرتها على بيانات عربية محكّمة.
