# تقرير التسليم والتحقق

## الموجود فعليًا

- مستودع Python/FastAPI وواجهة عربية RTL قابلة للتشغيل محليًا.
- مخططات JSON Schema، وهجرات Supabase لـPostgreSQL/pgvector، واختبارات CI.
- PDF المستخدم محفوظ محليًا ببصمة `e209f0cca8a26244` (بادئة SHA-256)، مع 152 صفحة مستخرجة و253 مقطعًا بحدود العناوين والفقرات.
- 103 سجلات أمثلة مرشحة و14 سجل قواعد مرشحة؛ جميعها `needs_review`.
- 20 مقترحًا تحليليًا منظمًا، مستندًا إلى مقاطع مقروءة من نفس الكتاب، مع سجل إصدار آلي دون اعتماد بشري.
- مطابقة آلية لجميع مقتطفات السجلات مع النص المستخرج باستخدام معرف المقطع والصفحة والإزاحات.
- تقرير تغطية لكل المقاطع، و12 حالة مرشحة لمراجعة المعيار اليدوي؛ ليست gold labels.
- مراجعة وتاريخ إصدارات، واسترجاع مقيد بالاعتماد، وامتناع، وتكرار وعائلات، وبوابة للبحث الخارجي، وتصدير محافظ على عزل المعيار.

## التحقق المنفذ

شُغلت اختبارات الوحدات وAPI محليًا. نجح 54 اختبارًا، وتُخطي اختبار PostgreSQL الحقيقي لأن خادمه غير متاح في جهاز التسليم؛ يعمل في CI. فُحصت صلاحية JavaScript، ومخططات السجلات، وجميع مواضع الاقتباس الـ117. شغلت واجهة المراجعة وأظهرت أعداد السجلات والمصدر والمقتطف وحقول التحرير؛ لم يُعتمد أي سجل أثناء الاختبار. جرى فحص الصفحة الأولى من PDF بصريًا لتثبيت عنوان الكتاب والمؤلف وطريقة ترتيب العربية.

## ما ينتظر تشغيلًا أو مراجعة فعلية

1. مراجعة بشرية علمية لجميع المرشحات ومقابلة الاقتباسات بالصفحات، واستكمال ما لا تلتقطه مؤشرات الاستخراج. وجود 103 فروع ليس ادعاءً بأن كل مثال ضمني اكتُشف.
2. تشغيل PostgreSQL/pgvector وCI في بيئة النشر، ثم فحص النسخ الاحتياطي والصلاحيات وحدود الخدمة. مخطط SQL مولد ومراجع، لكن لم يُنفذ محليًا على PostgreSQL.
3. اختيار وتوفير نموذج عربي للتضمين والتحليل، ثم معايرة التكرار وقياس RAG. الموفرات مبرمجة ومختبرة ببدائل حتمية؛ لم يُشغّل نموذج لغوي أو تضمين حقيقي في التسليم.
4. اعتماد gold labels قبل benchmark وJSONL للتدريب؛ عدد الحالات المعتمدة حاليًا صفر، لذلك لا توجد درجات نموذج مدعاة ولا تصديرات تدريب معتمدة.
5. استكمال مراجعة المصدر وتوثيقها قبل المرحلة الثانية. لم تُجمع أي اعتراضات خارجية ولم تُرسل مواد إلى مواقع أو نماذج بعيدة.

لم يُنشر مستودع GitHub أو موقع عام. الكود جاهز لرفع مستقل عن البيانات الخاصة. ملف الحزمة المحلية يتضمن مصدر المستخدم وبياناته غير المعتمدة لاستخدامه الخاص، ولا يمنح حقوق إعادة نشرها.

## تحديث 4 أكتوبر 2026: النشر والذكاء الاصطناعي

ما سبق يصف حالة التسليم الأولى. منذ ذلك الحين:

- النسخة المستضافة تعمل على Vercel مع Supabase (PostgreSQL + pgvector + تخزين خاص)، والكود في مستودع GitHub خاص. التفاصيل في [دليل النشر](deployment.md).

- الاختبارات: أكثر من 90 اختبارًا آليًا، منها اختبار PostgreSQL حقيقي في CI.
- ما زال عدد السجلات المعتمدة صفرًا حتى يراجعها الخبراء؛ لا توجد درجات أداء مدعاة.
