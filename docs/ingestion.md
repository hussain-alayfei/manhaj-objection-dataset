# إدخال PDF وفحص العربية

يحفظ المصدر: الأصل، SHA-256، النص الخام لكل صفحة، النص المرتب، طريقة الاستخراج، مؤشرات الجودة، وعدد الصفحة داخل PDF. التقسيم متصل داخل الصفحة وله بداية ونهاية حرفيتان، ويفضل حدود العناوين والفقرات والجمل. المقاطع لا تعبر صفحة؛ مثال الكتاب يمكن أن يستشهد بعدة مقاطع وصفحات.

ملف 15110.pdf يخزن ترتيبًا بصريًا معكوسًا. `pdfplumber` مع `char_dir=rtl` ثم قلب سطر الحروف يعطي ترتيبًا عربيًا مقروءًا. هذا تحويل **خاص بنمط الملف**؛ لا يفترض سلامته لكل PDF أو للنصوص المختلطة والأرقام والآيات المشكولة. عُرضت الصفحة الأولى للتحقق، وتظل المقابلة الشاملة مهمة بشرية. النص الخام متاح لفحص أي خلل في التحويل.

استخراج pypdf الافتراضي لا يقدم OCR. الصفحات ذات أقل من 20 حرفًا عربيًا ترفع `needs_ocr_or_nontext_page_review`، فقد تكون صورة أو صفحة غير نصية. لا تتحول إلى أمثلة مختلقة.

OCR محلي اختياري بعد تثبيت Tesseract وبيانات العربية:

```sh
python scripts/ocr_pdf.py book.pdf --pages 3 4 --output data/processed/ocr-pages.json
python scripts/ingest_book.py book.pdf --ocr-pages data/processed/ocr-pages.json
```

صفحات عارض الكتاب داخل الموقع صور WebP تُولَّد من PDF بعد إدخاله: `python scripts/render_source_pages.py SRC-<id>` يكتبها في `data/source/<id>/pages/` ويرفعها إلى الحاوية الخاصة حين `STORAGE_BACKEND=supabase`، بعد التحقق من مطابقة بصمة الملف للمصدر المُدخل. وتبقى خارج Git مثل الكتاب نفسه.

إعادة إدخال نفس بصمة PDF تسترجع المصدر الموجود ولا تستبدله. لاختبار إعداد استخراج مصحح قبل وجود مراجعات استخدم قاعدة اختبار جديدة. ترقية استخراج مصدر راجعه بشر تتطلب إجراء ترحيل يحفظ النسخة السابقة؛ لا يُسمح بالاستبدال الصامت. المصدر المرفق لا يحتاج OCR لاستخراج مرشح أولي.

البرمجية تحفظ كل فروع الكتاب التي تحمل `الفرع ... :` كمرشحات، إضافة إلى مؤشرات القواعد والأسئلة والمقارنات وطرائق الرد في تقرير كل مقطع. قد يحتوي الفرع على عدة أمثلة، وقد توجد قواعد خارج المؤشرات المحددة. المراجع ملزم بفحص التغطية، وإلا لا يصح إعلان اكتمال المرحلة الأولى.

## استخراج دلالي اختياري لجميع المقاطع

بعد ضبط مزود نماذج، يمكن تشغيل الأمر أدناه. مع `LLM_PROVIDER=openai` يستعمل OpenAI بنموذج `EXTRACTOR_MODEL` (أو `DIAGNOSIS_MODEL` إن لم يُضبط) و`EXTRACTOR_REASONING_EFFORT` الاختياري، ويُرسل نص كل مقطع إليه؛ وفي غير ذلك يستعمل Ollama المحلي (`EXTRACTOR_MODEL` و`OLLAMA_URL`). في النسخة المستضافة يعمل من سطر الأوامر فقط.

```sh
python -m src.cli extract SRC-e209f0cca8a26244 --model
```

يمر هذا المسار على جميع المقاطع ويقترح الأنواع الستة: القواعد، والأمثلة، والمقارنات، وأنماط الاستدلال، والأسئلة التشخيصية، ومنهج المعالجة. لا يقبل اقتباسًا إلا إذا طابق نصًا متصلًا فريدًا في المقطع؛ تحسب البرمجية الصفحة والإزاحات ولا تأخذها من النموذج. تحفظ العناصر في `source_items`، وتضاف القواعد والأمثلة إلى قائمة المراجعة. الأخطاء والاقتباسات المرفوضة محفوظة في تقرير التشغيل. لا يثبت نجاح التشغيل اكتمال التغطية، ولا يعتمد أي عنصر تلقائيًا. هذا المسار مبرمج ومختبر بموفر اصطناعي؛ لم يُشغّل نموذج حقيقي على الكتاب في بيانات التسليم.
